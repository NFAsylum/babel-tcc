# Tarefa 103 - Strings em runtime (i18n Camada C)

## Fase
7 - Internacionalizacao

## Objetivo
Localizar as mensagens exibidas em tempo de execucao pela extensao.

## Escopo
- Varrer src/ e levantar a lista completa de strings hardcoded voltadas ao usuario.
- Migrar cada string para vscode.l10n.t(...).
- Criar bundles l10n/bundle.l10n.pt-br.json e l10n/bundle.l10n.es.json (EN fica no codigo).
- Declarar o campo l10n no package.json.
- Corrigir uma mensagem por vez, validando os testes a cada passo.
- Idiomas da primeira leva: EN, PT-BR, ES.
