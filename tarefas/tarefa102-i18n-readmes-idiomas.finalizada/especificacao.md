# Tarefa 102 - READMEs por idioma (i18n Camada B)

## Fase
7 - Internacionalizacao

## Objetivo
Disponibilizar a documentacao principal em EN, PT-BR e ES, com README canonico empacotado na extensao.

## Escopo
- Definir o idioma canonico empacotado na .vsix.
- Traduzir o conteudo do README para os tres idiomas.
- Adicionar linha de navegacao entre idiomas no topo de cada arquivo.
- Ajustar copy-readme.js para empacotar o README canonico definido.
- Manter conteudo equivalente entre os tres idiomas.
- Idiomas da primeira leva: EN, PT-BR, ES.
